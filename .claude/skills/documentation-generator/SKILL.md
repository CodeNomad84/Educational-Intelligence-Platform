# Documentation Generator Skill

## Required Deliverables
When requested, assist in generating structured documentation files:
- **DEMO_GUIDE:** Step-by-step instructions on setting up and reviewing specific flows.
- **DEMO_SCRIPT:** A clean narrative template for live feature demonstrations.
- **Architecture Notes:** High-level diagrams, technical stack maps, and system design records.
