# Python / Django Expert Skill

## Scope of Work
Apply Django best practices to the following core areas:
- **Django Models:** Design clean schemas, fields, and relationships.
- **Management Commands:** Write robust custom admin commands.
- **Templates:** Build clean, reusable templates.
- **Views:** Optimize function-based or class-based views.
- **Migrations:** Generate, inspect, and safely execute database migrations.
